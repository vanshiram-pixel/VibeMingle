# VibeMingle Android (Flutter)

This directory is the Flutter workspace target. Initialize it locally with a current stable Flutter SDK:

```bash
flutter create --org com.vibemingle --project-name vibemingle .
flutter pub get
flutter analyze
flutter test
```

Before committing generated files, review the generated Android package, SDK levels, permissions, dependency licenses and CI configuration. Do not add camera/microphone permissions until the call UX and consent flows are implemented. No video chat is implemented by this README.
