# VibeMingle

VibeMingle is a social, stranger-matching and video communication product for Android and web, supported by an Admin/Ops console.

## Current authoritative specifications
- [V4 Final Hard Locks](docs/V4_FINAL_HARD_LOCKS.md) — consolidated scope, product invariants and release acceptance gates.
- [Final Master Product Blueprint](docs/FINAL_MASTER_PRODUCT_BLUEPRINT.md) — screen-by-screen product contract.
- [Master Roadmap](docs/MASTER_ROADMAP.md) — phased delivery and evidence-based status.
- [Unified Connections Social System](docs/CONNECTIONS_UNIFIED_SOCIAL_V4.md) — one social hub; Friends and Follow semantics remain distinct.
- [Stranger Matching](docs/instant-stranger-matching.md) — instant random, Next, manual search and match lifecycle.
- [Match → Friend Flow](docs/STRANGER_MATCH_FRIEND_FLOW.md) — friendship, canonical conversation and private-call consent.

## Version policy
V1/V2/V3 remain preserved scope tiers. V4 consolidates their hard locks and acceptance criteria. Specifications do not imply code is implemented or production verified. See roadmap for actual evidence/status.

## Development
Work on feature branches and keep production deployment/store launch behind explicit user approval. No mock/fake completion should be represented as production functionality.
